## Proyecto destacado

### Porto-Muíños App

Proyecto Fin de Ciclo de DAM desarrollado de forma individual para Porto-Muíños.

Aplicación Android orientada a la consulta de productos y recetas, con funcionalidades de búsqueda, favoritos, carrito y lectura de códigos QR.

Desarrollada con Kotlin y Jetpack Compose, arquitectura MVVM/Repository y backend con Supabase/PostgreSQL. Incluye autenticación mediante email y Google, gestión de acceso con RLS e integración con servicios backend.

El proyecto incluyó diseño, desarrollo, documentación técnica, generación de APK firmada y defensa final.

**Calificación: 10/10.**

[Ver Porto-Muíños App en GitHub](https://github.com/miguelfernandezg/PortoMuinos)
